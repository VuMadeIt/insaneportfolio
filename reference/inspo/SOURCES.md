# Visual inspo (not shipped)

New references collected 2026-11-03. Use for layout / interaction feel — not for copying
branding, type, or rounded-card aesthetics that conflict with PLAN.md (museum-white, Fraunces,
square corners).

## Files

- `lucas-vu-hero-mock.png` — Lucas's own hero frame: top-left status lines, four hanging white
  spheres, vertical right-edge line ("the person who gets things moving"), giant **LUCAS VU** at
  the bottom. Closest composition sketch for the cradle hero + tagline placement.
- `studio-wentape-accordion.png` — Studio Wentape site frames: numbered accordion sections
  (01 Featured Works → 05 Contact) that expand in place; rigid black rules; monochrome UI with
  colour only in media. Take the **accordion expand / collapse rhythm** and hairline sectioning —
  not the Bauhaus asterisk, Inter/Helvetica look, or agency header CTA.
- `editorial-tibetan-culture-layouts.png` — Xiaohongshu editorial spreads ("The Origin of Tibetan
  Culture"): paper-texture ground, generous negative space, photo as exhibit, small corner labels,
  multi-column image strips. Take the **museum/scrapbook calm** and photo-as-object treatment —
  not the scrapbook collage density or watermark styling. Source watermark: Little Red Book /
  Xiaohongshu id 9577374185.
- `20261103-1427-09.8724131.mp4` — Lucas screen recording (Snipping Tool / Screen Sketch,
  2026-11-03). Motion / interaction reference for the inspo above; keep alongside the stills when
  judging scroll and expand feel.
